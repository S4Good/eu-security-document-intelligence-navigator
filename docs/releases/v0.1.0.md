# Release Notes — Document Intelligence Navigator v0.1.0

First usable Windows offline release of **EU Security & Privacy Document Intelligence Navigator**.

> Information-retrieval demonstrator only. It does not provide legal advice or compliance certification.

---

## Highlights

- **Offline, Single-User Windows Launch**: Runs locally on `127.0.0.1` without a separate Python installation, `.env` file, or cloud connection. Cloud SDKs (`azure`, `python-dotenv`) are excluded from the packaged Windows bundle.
- **Text-Based PDF & JSON Search**: Open multiple local text-based `.pdf` and UTF-8 `.json` files in one session and search across them offline. Each result displays the filename, cleaned excerpt, and exact PDF page number or RFC 6901 JSON Pointer field path.
- **Direct Citation Navigation**:
  - **PDF page jump**: Click **Open PDF at page N** to stream the in-memory PDF inline to `#page=N` in your browser.
  - **Nested JSON field inspection**: Click **Inspect JSON field** to view the matched value and surrounding JSON object context safely in the UI.
- **In-Memory Only & Session Cleanup**: Uses a bounded, purely in-memory multipart upload parser (verified with >1 MB synthetic PDF and JSON files to write `0` temporary files to `%TEMP%`). Clicking **Clear session** or exiting the console (`Ctrl+C`) removes all imported files and search results immediately.

## Unzip and Run (Windows x64 — No Python Required)

1. Download **`DocumentIntelligenceNavigator-windows-x64.zip`** (and optionally **`DocumentIntelligenceNavigator-windows-x64.zip.sha256`**) from this release.
2. *(Recommended)* Verify the SHA-256 checksum in PowerShell:
   ```powershell
   Get-FileHash .\DocumentIntelligenceNavigator-windows-x64.zip -Algorithm SHA256
   ```
3. Extract the archive (right-click → **Extract All…**, or in PowerShell):
   ```powershell
   Expand-Archive .\DocumentIntelligenceNavigator-windows-x64.zip -DestinationPath .\DocumentIntelligenceNavigator-v0.1.0
   ```
4. Launch the executable:
   ```powershell
   .\DocumentIntelligenceNavigator-v0.1.0\DocumentIntelligenceNavigator\DocumentIntelligenceNavigator.exe
   ```
   *(If Windows SmartScreen prompts because this first release is unsigned, verify the SHA-256 hash above before choosing **More info → Run anyway**, or build locally from source with `.\scripts\build_windows.ps1`.)*
5. Your default browser opens **`http://127.0.0.1:8000/search`** (or the next free localhost port if `8000` is busy).
6. Drag and drop or select one or more text-based `.pdf` or `.json` files, search across them, open cited pages/fields, and click **Clear session** (or press `Ctrl+C` in the terminal window) when finished.

## Supported Inputs & Limits

- **Supported formats**: Text-based `.pdf` files and UTF-8 `.json` files (including UTF-8 with BOM).
- **Session limits**: Up to `50` files per session, `25 MB` per file, `100 MB` total session size, `500` pages per PDF, `64` JSON nesting levels, and `50,000` indexed JSON fields per file.
- **Actionable errors**: Unsupported extensions, empty files, malformed JSON, corrupted PDFs, encrypted PDFs, and oversized uploads return clear per-file error messages without crashing the session.

---

## Current Limitations

- **No OCR in v0.1.0**: Scanned or image-only PDFs without an embedded text layer cannot be indexed offline. They are detected and rejected with an explicit message rather than silently returning zero hits.
- **No Encrypted PDF Support**: Password-protected PDFs must be decrypted locally before importing.
- **Browser-Side Caching Note**: API responses send `Cache-Control: no-store`, `Pragma: no-cache`, `X-Content-Type-Options: nosniff`, and `Referrer-Policy: no-referrer`, though standard browser history/extensions remain managed by your browser.
